# Building StorageSorter

**English** | [日本語](#日本語)

## English

### Requirements
- [.NET SDK](https://dotnet.microsoft.com/download) 8 or newer
- Supermarket Together (the game DLLs are referenced from your install, not included in this repo)
- BepInEx 5 installed through a mod manager profile (e.g. Thunderstore Mod Manager / r2modman)

### Setup
1. Copy `UserPaths.props.example` to `UserPaths.props`.
2. Set `GameManaged` to the game's `Supermarket Together_Data\Managed` folder and `ProfileDir` to your mod manager profile.
   (You can also pass them on the command line: `-p:GameManaged=... -p:ProfileDir=...`.)

### Build
```
dotnet build -c Release
```
- Output: `bin/Release/net472/StorageSorter.dll`
- A Release build also creates the Thunderstore upload zip: `bin/thunderstore/penguin4glte-StorageSorter-<version>.zip`
- `-p:DeployToProfile=true` copies the DLL into `<ProfileDir>/BepInEx/plugins/StorageSorter/` for quick testing.
  Disable the Thunderstore-installed copy first, or the mod loads twice.

### Tests
The sorting logic (`StoragePlanner.cs`) has no Unity dependency and is tested without the game:
```
dotnet run --project tests/StorageSorter.Tests
```

### Releasing a new version
Update the version in **three places**: `StorageSorter.csproj` (`<Version>`), `Plugin.cs` (`PluginVersion`) and `thunderstore/manifest.json` (`version_number`), then add an entry to `CHANGELOG.md`.

### Project layout
| File | Role |
|---|---|
| `Plugin.cs` | BepInEx entry point, config, hotkey |
| `StorageSortRunner.cs` | Reads the shelves, applies the plan in two phases (clear → refill) |
| `StoragePlanner.cs` | Pure sorting/merging logic (unit-tested) |
| `SortGuardPatches.cs` | Harmony patches that pause employee/host storage actions during a sort |
| `OaoBridge.cs` | Optional OrderAndOrganize integration via reflection |
| `Loc.cs`, `lang/` | Message localization |
| `Notifier.cs` | In-game notification |
| `thunderstore/` | `manifest.json`, `icon.png` (generated by `make_icon.ps1`) |

## 日本語

### 必要なもの
- [.NET SDK](https://dotnet.microsoft.com/download) 8 以降
- Supermarket Together（ゲームの DLL はインストール先から参照します。このリポジトリには含まれていません）
- Mod マネージャー（Thunderstore Mod Manager / r2modman など）のプロファイルに入った BepInEx 5

### 準備
1. `UserPaths.props.example` を `UserPaths.props` にコピーします。
2. `GameManaged` にゲームの `Supermarket Together_Data\Managed` フォルダ、`ProfileDir` に Mod マネージャーのプロファイルを指定します。
   （コマンドラインで `-p:GameManaged=... -p:ProfileDir=...` と渡すこともできます）

### ビルド
```
dotnet build -c Release
```
- 出力：`bin/Release/net472/StorageSorter.dll`
- Release ビルドでは、Thunderstore にアップロードする zip（`bin/thunderstore/penguin4glte-StorageSorter-<バージョン>.zip`）も作られます。
- `-p:DeployToProfile=true` を付けると、テスト用に DLL を `<ProfileDir>/BepInEx/plugins/StorageSorter/` にコピーします。
  Thunderstore から入れた版を先に無効にしないと、二重に読み込まれます。

### テスト
並び替えのロジック（`StoragePlanner.cs`）は Unity に依存しないので、ゲームなしでテストできます。
```
dotnet run --project tests/StorageSorter.Tests
```

### 新しいバージョンを出すとき
バージョン番号を **3 か所** 更新します：`StorageSorter.csproj`（`<Version>`）、`Plugin.cs`（`PluginVersion`）、`thunderstore/manifest.json`（`version_number`）。そのあと `CHANGELOG.md` に追記します。
